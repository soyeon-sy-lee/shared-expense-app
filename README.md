# 우리지출 웹앱

카드 지출에서 공동지출을 자동 분류하고, 정산 입금액을 반영해 실질 소비액을 계산하는 개인용 웹앱입니다.

## 월별 데이터 입력

화면 오른쪽 위의 **월별 데이터 입력**에서 월을 선택하고 카드 CSV와 계좌 CSV를 넣습니다. 같은 월을 다시 저장하면 기존 입력을 교체하므로 중복 누적되지 않습니다.

카드 CSV 필수 열:

- 날짜: `이용일`, `매출일`, `거래일`, `날짜`, `거래일자`
- 가맹점: `가맹점명`, `이용가맹점`, `가맹점`, `거래내용`, `적요`
- 금액: `이용금액(원)`, `이용금액`, `매출원금`, `출금액`, `금액`
- 선택 열: `업종`, `카테고리`, `분류`

계좌 CSV 열:

- 날짜: `거래일`, `입금일`, `날짜`, `거래일자`
- 입금액: `입금액`, `입금금액`, `받은금액`, `금액`
- 선택 열: `적요`, `거래내용`, `입금자`, `보낸분`, `의뢰인`, `메모`

콤마 구분 CSV와 엑셀에서 복사한 탭 구분 데이터를 모두 인식합니다. 월별 입력은 로컬 개발 환경의 D1 저장소에 보존됩니다.

## 실행

```bash
pnpm install
pnpm run dev
```

기본 주소는 `http://localhost:3000/`입니다.

## 개인정보와 GitHub 공개 데이터

- 실제 거래 데이터는 `.private/transactions.json`에 보관되며 Git에서 제외됩니다.
- 로컬 개발 서버는 실제 데이터를 우선 사용하고, 파일이 없으면 공개 데모 데이터로 자동 전환합니다.
- `public/data/transactions.json`에는 공동지출·승인필요·개인지출 대표 거래가 각각 5건만 포함됩니다.
- 입금 적요는 공개 파일에서 `예시 정산 입금`으로 익명화됩니다.
- `pnpm run data:public`으로 공개 샘플을 다시 만들고, `pnpm run privacy:check`로 공개 전 검증할 수 있습니다.
- 빌드는 개인정보 검사를 먼저 통과해야 시작됩니다.
